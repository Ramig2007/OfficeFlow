# Матрица обязательных требований ИСП49

**Источник:** преподавательский кейс «Онлайн-сервис бронирования переговорных комнат в офисе», разделы 1–8. Статусы разделяют реализацию, фактические проверки и незакрытые пункты. «Проверено» означает только описанный в документах сценарий и среду; это не подтверждение SLA или промышленной готовности.

## Критерий финального закрытия

Уже подтверждены локальный Docker стенд, 60/60 pytest, 91,67% покрытия двух критических модулей, PostgreSQL concurrency CI, 9/9 read-only Playwright checks, 8/8 ручных пользовательских сценариев, краткий read-only k6 тест и backup/restore во временную БД. До полного закрытия ИСП49 остаются: VPS deploy и внешний HTTPS smoke-test (если хостинг обязателен), off-host backup, фактический receiver Alertmanager (если требуется), write workload/большая нагрузка при необходимости, формальная приёмка, скриншоты и итоговый Word-отчёт. SLA 99,9% и 1000 пользователей не заявлять без соответствующих измерений.
