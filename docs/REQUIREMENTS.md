# Матрица обязательных требований ИСП49

**Источник:** прикреплённый преподавательский кейс «Онлайн-сервис бронирования переговорных комнат в офисе», разделы 1–8, 3 страницы. Состояния: **код** — реализация подготовлена, но ещё не подтверждена запуском; **конфигурация** — есть конфигурационные/методические файлы; **приёмка** — нужен фактический протокол, измерение или действие студента. Эта матрица намеренно не объявляет непроведённые испытания успешными.

Запустить в PostgreSQL, выполнить весь test suite, E2E и нагрузки 100–200 RPS на бизнес-эндпоинтах, доказать покрытие ≥70% критических модулей, проверить реальные метрики и фиксацию ошибок; заполнить пилотный отчёт и приложить ссылки на GitHub Actions, Docker image и скриншоты реального UI.
