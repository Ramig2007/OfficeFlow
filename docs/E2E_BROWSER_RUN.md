# OfficeFlow: браузерные E2E-тесты

## Назначение

`e2e/browser_smoke.py` открывает реальный Chromium, проверяет вход через HTML-форму, панель,
каталог, переход на карточку переговорной, VIP-фильтр, расписание, историю,
серверную блокировку административных маршрутов для сотрудника и мобильное отображение.
Это **read-only smoke-test**: он **не создаёт, не изменяет и не отменяет** бронирования.
Он дополнен отдельным E2E-тестом создания и отмены, который следует запускать только
на изолированном демостенде, после получения разрешения на изменение тестовых данных.

Скриншоты сохраняются на локальном ПК в `e2e/artifacts/`.

## Запуск из PowerShell (в папке OfficeFlow)

1. Убедиться, что рабочий сайт и `docker compose ps app` показывают `healthy`.
2. Установить `K6_USERNAME` и `K6_PASSWORD` в **том же терминале**, где будет запускаться тест:

```powershell
$env:K6_USERNAME = 'employee'
$secure = Read-Host 'Введите пароль employee' -AsSecureString
$env:K6_PASSWORD = [System.Net.NetworkCredential]::new('', $secure).Password
Remove-Variable secure
```

3. Один раз собрать браузерный образ (первый запуск потребует скачать образ браузера):

```powershell
docker build -f e2e/Dockerfile.browser -t officeflow-e2e e2e
```

4. Запустить:

```powershell
docker run --rm --ipc=host --network officeflow_internal --env K6_USERNAME --env K6_PASSWORD -e BASE_URL=http://proxy -v "${PWD}\e2e:/tests" officeflow-e2e
```

Ожидаемый конец вывода: `RESULT: 9/9 browser checks passed`. Это **ожидаемый**, а не
заранее подтверждённый результат. Если тест обнаружил дефект, получите `FAIL` и скриншот.

После завершения можно очистить пароль: `Remove-Item Env:\K6_PASSWORD`.

## Область действия и ограничения

- Проверяются только перечисленные сценарии. Нагрузка 200 RPS и конкурентная запись
  проверяются другими тестами.
- Рабочее приложение и его данные не модифицируются.
- Запускайте на доверенном локальном стенде. Во время работы пароль находится в окружении
  временного контейнера; не отправляйте скриншоты терминала с секретами.
- Доступность 99,9% и готовность к эксплуатации этим тестом не подтверждаются.
- Имя `compose.override.yaml` Git сам по себе не исключает. Для воспроизводимости
  зафиксируйте только **несекретную** конфигурацию 4 workers в репозитории;
  пароль и `.env` в Git не добавлять.
