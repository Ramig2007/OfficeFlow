# План разработки и оценка трудозатрат

Все трудозатраты — плановые диапазоны, не реальное затраченное время. Переход к следующему этапу допускается только после закрытия критических дефектов предыдущего. Наработанные файлы первого этапа и скелет последующих этапов входят в текущий архив.

| Этап | План, человеко-часы | Результат | Критерий готовности |
|---|---:|---|---|
| 1. Проектирование | 6–10 | матрица, C4, ER, роли, сценарии | все требования ИСП49 сопоставлены с доказательствами |
| 2. База и среда | 10–16 | Django, PG, Redis, Docker, auth | чистое `docker compose up`, миграции, вход |
| 3. Бронирования | 18–28 | модели, сервисы, API, календарь | конфликт PG/гонка, 1–4 ч, история, отмена |
| 4. VIP и CSV | 8–14 | approve/reject, report filters/export | запрет обхода, tests, impact analysis |
| 5. UI и адаптив | 14–22 | светлая система, 12 страниц | сценарии на desktop/tablet/mobile |
| 6. Качество | 14–24 | тесты, E2E, линтер, CI, security | ≥70% critical modules, CI green |
| 7. Эксплуатация | 12–20 | метрики, алерты, load, backups | отчёты 100/200 RPS, проверка restore |
| 8. Приёмка | 8–14 | дефект-реестр, регрессия, отчёт | критические дефекты закрыты, приложены доказательства |
| **Итого** | **90–148** | учебная работа | подтверждённая приёмка |

## Сценарии приёмки

- Сотрудник открывает календарь, выбирает комнату и бронирует 2-часовой слот.
- При занятом слоте видит сообщение об ошибке; другая комната/время доступна.
- VIP-заявка сохраняется только как pending; администратор одобряет/отклоняет.
- В истории видны прошлые отменённые/отклонённые встречи.
- Менеджер отключает комнату без потери записей, меняет пользовательскую роль.
- Отчёт фильтруется и выгружается в CSV.
- OpenAPI, CI, мониторинг, backup/restore проверены отдельно.

## Зависимости и ограничения

Docker Desktop, работающий интернет при первом скачивании контейнеров/пакетов, свободные порты 8080/3000/9090, тестовые аккаунты, PostgreSQL. Настоящие результаты нагрузок и интерфейсных скриншотов можно получить только после развёртывания. Для сдачи нужен собственный GitHub URL и заполненный итоговый отчёт.
