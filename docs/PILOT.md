### Новый смешанный нагрузочный профиль

В текущей ветке `scale-validation/final-gap-closure` обновлён новый `scripts/loadtest-mixed-100-rps.js`, который уже вызывается `scale-validation.yml`.

Одна итерация выполняет один авторизованный HTML GET и три API write-запроса (create/edit/cancel). Верхняя ступень 25 итераций/с соответствует **100 HTTP RPS**: 25 read + 75 write. Заданы пороги p95 <200 мс, HTTP error rate <0,1%, checks >99,9% и ноль dropped iterations.

**Статус результата:** ожидает запуска CI текущего PR. До успешного run этот профиль нельзя указывать как пройденный.

## 5. Мониторинг, алерты и резервирование

- Prometheus: 3/3 targets UP в локальном стенде.
- Prometheus alert rules: 5 правил прошли `promtool test rules`.
- Grafana dashboard: конфигурация подготовлена, локальный observability stack запускался.
- Alertmanager: default receiver — `null-receiver`; реальная доставка не включена без HTTPS webhook.
- Конфигуратор webhook поддерживает HTTPS URL и optional Bearer token; unit tests добавлены в текущей ветке, ожидают CI.
- Backup: локальный dump и independent restore проверены CI #117.
- Off-site: добавлены S3 upload + SHA-256 verification script, systemd timer/service и mock tests. Настоящий S3 bucket, IAM и удалённый restore ещё не выполнены.
- SLA 99,9%: не измерен за 30-дневное окно. Uptime probe и report scripts готовы; нужен публичный HTTPS URL и независимый monitoring host.
