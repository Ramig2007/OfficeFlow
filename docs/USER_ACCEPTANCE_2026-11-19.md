## Сопутствующие технические подтверждения

- Django: локально 60/60 тестов; в CI подтверждён успешный этап `quality`, ранее зафиксировано покрытие критических модулей 91,67 %.
- Playwright: 9/9 браузерных проверок, по результатам локального прогона.
- Нагрузочный тест авторизованного чтения: целевые 200 RPS, 6 001 успешная проверка, p95 13,19 мс, 0 HTTP-ошибок; тест продолжался 30 секунд.
- Резервное копирование и восстановление PostgreSQL: восстановление во временную БД выполнено успешно; числа записей совпали, проверено ограничение от пересекающихся броней.
- Prometheus: три источника метрик в состоянии `up`; 5 правил проверены `promtool test rules` (`SUCCESS`).
- Alertmanager: тестовый алерт принят и маршрутизирован в `null-receiver` (реальная доставка сообщений не настроена).
- GitHub Actions: основной `main` run #5 прошёл; PR #1 с production-подготовкой прошёл run #6 (`quality` и `docker` — Success). После последних документальных изменений выполняется повторный CI.

## Ограничения выводов

Эта проверка проведена одним пользователем в локальной среде. Она **не** является доказательством SLA 99,9 % за длительный период, безопасной промышленной эксплуатации, работы при 1 000 одновременных пользователях, производительности операций записи под нагрузкой или независимой приёмки несколькими пользователями. Исходный GitHub-репозиторий публичный. GHCR package остаётся Private, поэтому скачивание образа преподавателем требует доступа к пакету или альтернативной сборки из публичных исходников. Внешнее развёртывание требует отдельной проверки.
