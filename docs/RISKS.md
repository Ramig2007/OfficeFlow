# Реестр рисков OfficeFlow

Шкала: вероятность (Н/С/В), влияние (Н/С/В). Владелец — студент/разработчик при учебной эксплуатации.

| Риск | Вероятность | Влияние | Профилактика / реакция |
|---|---|---|---|
| Двойное бронирование из двух запросов | С | В | PG `EXCLUDE USING GIST` + row lock + concurrency test |
| VIP обходится через API/admin | С | В | status назначает сервер; Django admin change/delete disabled; 403 тест |
| SQLite тест выглядит успешным при гонке | В | В | обязательно прогонять PostgreSQL CI |
| Миграция PG отклонена из-за прав btree_gist | С | В | проверка `CREATE EXTENSION`; запуск на официальном PG |
| 100 RPS недостижимы с dev Compose | В | С | измерить профиль, масштабировать за LB, оптимизировать ORM |
| 99,9% на одной БД недостижимы | В | В | managed PG/standby и проверенные backups для production |
| Недоступный Redis ломает сессии | С | С | readiness, мониторинг, резервный план на DB-backed sessions |
| Утеря данных / ошибочное восстановление | С | В | backup вне хоста, подтверждение restore, тест восстановления |
| CSV формулы выполняются у получателя | С | С | безопасное экранирование и регрессионные тесты |
| Персональные данные в логах | С | В | журнал без содержимого секретов; ограничение прав и сроков хранения |
| CSRF/IDOR/role escalation | С | В | SessionAuthentication с CSRF, owner checks, security tests |
| Переход DST / неоднозначный час | Н | С | aware timestamps, тесты timezone и UX для зон с DST |
| Ошибка конфигурации Secret Key/DB pass | С | В | `.env` в gitignore, обязательные переменные, change demo creds |
| Слишком узкий охват тестами | В | В | coverage gate критических модулей, E2E и pilot checklists |
| Демонстрационные пароли опубликованы | С | В | seed_demo только при DEBUG=1; заменить все значения в `.env` |
| Промышленная готовность объявлена без проверок | В | В | явно разделять код/конфигурацию/измерения/приёмку |

Невыполненные мероприятия должны попасть в дефект-реестр/план корректирующих работ после пилота.
